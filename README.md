# Team CSE341 Project

This repository contains a collaborative backend web development project built with **Node.js, Express, and MongoDB**.  
The focus of the project was to design and implement RESTful APIs, integrate a NoSQL database, and support CRUD operations for application data.

## My Role
I contributed primarily to the **backend development**, with emphasis on:
- Setting up and configuring **MongoDB** connections
- Designing and managing collections for data persistence
- Implementing **CRUD endpoints** (Create, Read, Update, Delete)
- Ensuring efficient queries and secure database interactions
- Collaborating with teammates on API design and testing

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Git/GitHub for version control
